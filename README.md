# WhatsApp Web Backend

Node.js & Express backend for WhatsApp Web message scraping, multi-tenant QR code management, real estate property parsing, and realtor data isolation.

## Features
- Multi-tenant client data isolation (`user_id` scoping for QR codes, chats, and messages).
- Socket.IO real-time QR code broadcasting.
- Real estate listing normalization, price (PKR), and land area unit parsing.
- RESTful API endpoints for WhatsApp chats, realtors list, and message history.
